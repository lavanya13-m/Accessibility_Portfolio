# Accessibility Portfolio

Small, focused projects built while learning web accessibility fundamentals (WCAG 2.x, WAI-ARIA), each tested with NVDA, axe DevTools, WAVE, and Lighthouse.

## Projects

### profile-page
A semantically structured HTML page — proper heading hierarchy, semantic landmarks, functional alt text, accessible contact links. Verified clean (0 errors) on axe and WAVE, 100/100 on Lighthouse.

### faq-accordion
An accessible FAQ accordion using aria-expanded and aria-controls to communicate open/closed state to assistive technology. Confirmed working correctly with NVDA — announces "expanded"/"collapsed" on activation.
